\# Pipeline Methodology



\## Data Sources



Gaia DR3

Pan-STARRS DR2

Legacy Survey DR10

SDSS DR16

DESI DR1



\## Selection Workflow



Stage 1:

Gaia astrometric filtering



Stage 2:

Color filtering



Stage 3:

Pan-STARRS morphology



Stage 4:

Gaia DSC classifier



Stage 5:

Ranking



\## Scoring System



Gaia extragalactic astrometry = +2

Gaia galaxy probability >0.8 = +3

PS1 extension >0.8 = +3

Blue color = +1



Maximum score = 9



\## Known Failure Modes



Legacy Survey API outages

Gaia archive schema changes

Missing photo-z catalogs

Spectroscopic incompleteness
